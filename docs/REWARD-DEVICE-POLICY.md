# 设备阶梯奖励

后台「运营设置」中的设备阶梯奖励支持开关、固定模式金币、报价有效期、新设备/活跃设备的天数与完成及在途次数、成熟和未知设备的金币区间。策略由服务端保存版本及审计，默认启用阶梯模式。

设备阶段依据本服务首次见到的已验签设备、跨账号完成次数及未过期广告会话占位计算。它表示接入后的使用阶段，不代表手机购买日期；卸载或清除 Keystore 可能改变设备身份。历史已签设备按 keyId 迁移至平台 deviceId，保留首次记录与计数。

普通红包打开后先获得限时锁定报价。有效报价复用，不能靠关开弹窗反复重抽；开播时再核对设备、策略版本和名额。报价失效明确重新打开，已开始会话一直按原金币完成。未知设备仅使用后台设定的保守报价，SDK 不可用仍拒绝收益操作。

实际业务接口与设备报告绑定：更改账号、任务、报价、金额、收款对象或红包雨场次不能复用旧授权。业务效果与本地幂等记录同事务，回执失败可补报。规则细节、策略快照与设备依据只显示在管理中心，消费者只看到预计区间及本次锁定金币。
