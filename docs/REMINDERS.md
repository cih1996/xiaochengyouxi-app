# 通知提醒（手机通知栏，本地提醒）

不接第三方推送服务：App 在离开前台时按服务端配置安排本地提醒（AlarmManager 窗口闹钟，无需精确闹钟权限），回到前台时全部取消；到点由 `ReminderReceiver` 在通知栏显示，点击打开 App 并进入对应页面。

| 提醒 | 时机 | 点击后 |
|---|---|---|
| 红包雨开场 | 最近一场开始前 10~1 分钟（文案中 `{minutes}` 按触发时剩余分钟数替换；已开场则不弹）。每次离开 App 只安排下一场，不会每场都提醒 | 大厅 |
| 签到 | 当天未签到时，设定时间起 15 分钟内 | 签到 |
| 幸运转盘 | 转盘开启且当天仍有次数时，设定时间起 15 分钟内 | 转盘页 |

- 免打扰时段内的提醒不安排（默认 22:30–08:00）。
- 配置：后台「运营管理 → 通知提醒」；App 读取 `GET /api/app/reminders`（公开，无用户数据），后台 `GET/PUT /api/admin/reminders`（管理审计）。
- 权限：Android 13+ 需通知权限。首次签到成功后先说明用途再申请一次；之后可在「我的 → 设置 → 通知提醒」开关（关闭后取消已安排的提醒；系统层面关闭时引导到系统设置）。
- 局限：本地提醒依赖 App 曾被打开；部分国产系统在用户划掉后台后可能拦截闹钟。需要后台随时推送时，再接厂商推送通道。
