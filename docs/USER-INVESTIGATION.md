# 用户调查与审计

入口：https://orange.lingzidev.com/admin → 用户管理 → 点击用户。

用户列表支持账号、邀请与账户状态等条件。用户明细展示资料、邀请上下游、收支、广告会话及回调、提现、行为、风险、设备关联及管理审计；各记录支持分页、时间、类型、状态、金额及关联号等适用条件，关联账号可继续点入。

账户处理可设为正常、待核查或受限，必须填写原因。待核查与受限会阻止新的奖励和提现；已经完成的账本保持真实，重复完成请求不二次入账。恢复后的新事件继续按策略评估。

历史账本、奖励会话、邀请及提现从已有业务表追溯。登录尝试、无效回调、真实请求 IP、设备签名报告与管理员访问审计从本版启用后采集，后台显示采集起点。大厅消息仍只在客户端内存保存。

管理 API 全部要求管理令牌，普通账号令牌不能访问。审计保留操作者、时间、请求号、条件、结果和状态变更；密码、验证码、访问令牌与私钥不进入正文。

DeviceTrust 风险证据仅管理端展示。签名已验证、硬件证明与客户端自报信号分开理解；当前签名模式不代表硬件真实性验证。卸载重装或清除数据可能生成新设备密钥。

当前短信、提现付款与商品返佣仍为测试实现；真实广告填充及 SDK 真机验证仍需可联网 Android 设备完成。
