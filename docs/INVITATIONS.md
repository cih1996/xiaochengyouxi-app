# 小橙有喜邀请流程

每个账号获得独立的 6 位大写字母数字邀请码，避开易混淆的 `I/O/0/1`。邀请码与邀请关系固定，绑定不发放额外金币。

## 推广注册

1. 已绑定用户打开“我的 → 邀请好友”，复制链接或保存、分享个人二维码海报。
2. 好友扫码打开 `https://orange.lingzidev.com/i/<邀请码>`，输入手机号建立预绑定。
3. 好友使用同一手机号注册或密码登录后，服务端自动承接预绑定关系。

当前推广页手机号提交保持测试流程；未来接入真实短信时增加验证码校验。预绑定统计与已注册邀请统计分开计算。

## 直接注册

首次登录和恢复登录都会检查邀请绑定状态。未绑定时只进入邀请码页，填写有效邀请码后进入大厅；选择暂不绑定或返回则退出账号并回到登录页。服务端同时拦截未绑定账号的奖励、提现、流水和消息推送接口。

## 首批用户

管理后台“邀请管理”展示平台邀请码、平台推广链接、邀请统计和绑定记录。当前平台引导码为 `JZ8F6A`，可用于首批用户；管理端可配置。平台二维码示例：

- 链接：<https://orange.lingzidev.com/i/JZ8F6A>
- 海报：<https://orange.lingzidev.com/assets/invite-platform.png>

个人海报使用本人独立邀请码和对应链接。海报尺寸 1080×1600，真实二维码由服务器编码，Android 和网页直接绘制；二维码保留 4 模块静区。两端导出的海报均已使用独立解码器验证。

修改平台码后应重新生成对应的平台海报。既有绑定和已建立的预绑定保持原有关系。
