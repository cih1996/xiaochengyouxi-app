# 红包雨素材

使用内置 imagegen 生成，保留原始透明 PNG，未覆盖既有素材。

- 普通红包：`D:\工作\android-apps\orange-rewards\web\public\assets\rain-small.png`
- 大奖红包：`D:\工作\android-apps\orange-rewards\web\public\assets\rain-large.png`
- 天空云层：`D:\工作\android-apps\orange-rewards\web\public\assets\rain-sky.png`

三张均为真实 RGBA 透明图。普通红包使用橙红纸面与水果圆扣；大奖使用独立皇冠、金翅、金边和光晕；天空图中央及下方透明，用作顶部云层装饰。

完整提示词保存在同目录 `RAIN-IMAGE-PROMPTS.json`。网页与 Android 使用相同原图，飘落、脉冲、光效和倒计时由界面动画实现。
