# 红包雨

后台进入「红包雨」设置开关、北京时间起始整点、每隔几小时、持续时间、每人单场数量、小红包金币范围、大包概率与金币、每人单场金币上限、天空遮罩浓度、下落速度及同时可见数。「马上开一场」至少预留 10 秒倒计时。

默认每小时整点、持续 45 秒，每人最多 24 个红包，小红包 1–5 金币、大包概率 4%、88 金币，每人单场分配上限 300 金币。数量、概率和预算均由服务端控制。每场使用配置快照；关闭总开关立即停止新的领取，已经开始观看的大包继续按有效广告回调完成。

大厅顶部固定展示下场倒计时，消息列表独立滚动，最后 10 秒出现可关闭提醒。雨层也可收起；普通红包与带金冠、金翅、光晕的大红包使用独立图片。领取新的金币后播放金币声、显示飘字并同步账户余额；重复结果只同步余额。

场次开始前只提供时间信息。参与时通过账号与设备核验，服务端为该用户该场生成固定、随机的临时 ID 组；重新进入取回原组。领取接口只接收红包 ID，金额取服务端记录，并校验归属、实际时间、出现窗口、开关、领取间隔及状态。金币账本和红包状态同事务，`rain:{packet_id}` 唯一，重复请求不重复发币。

大包点击不入账。用户确认看视频后，使用独立的奖励设备事件创建穿山甲会话；服务器广告回调验签、用户/会话/金额校验和完成防重都通过后才记账。普通网页的正式模式提供 App 参与入口。本地 mock 只支持小包体验，大奖不使用倒计时模拟广告成功。

管理员可在用户明细按红包雨奖励及行为筛选，追溯参与、领取、大奖会话和账本；后台保存运营设置和手动开场的审计。设备签名是持钥证明，当前未启用硬件证明，不将时间窗和限量校验描述为真实手指点击证明。

界面素材与内置 imagegen 生成记录见 `RAIN-ASSETS.md` 和 `RAIN-IMAGE-PROMPTS.json`。
