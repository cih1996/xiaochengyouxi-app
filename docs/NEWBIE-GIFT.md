# 新人礼包（邀请大红包）

后台“运营管理 → 新人礼包”配置；默认关闭。服务端 `server/src/newbie.rs`，活动页 `web/public/activity/newbie.html`（网页发布即可改版，不需要发 APK），App 0.3.24 起有自动弹出、右上角悬浮礼包和海报分享。

## 规则

- **期（round）**：后台“开启新一期”后，本期之后注册的用户可领新人红包；老用户可再次被邀请参与。上一期未拆的红包不再显示。
- **新人红包**：每人每期 1 个。条件：本期内注册，或本期接受了好友邀请。金额按**本人**最新 DeviceTrust 风险分查“新人红包档位”；通过邀请注册的新用户再乘以“受邀新用户加成”（双向奖励）。
- **邀请红包**：被邀请人加入本期后，完成首次签到或领取首个红包，且已有设备风险分，邀请人得 1 次。金额按**被邀请人**的风险分查档：新用户用“邀请新用户档位”，老用户用“邀请老用户档位”。每人每期上限可配。
- 风险分：`risk_events` 最新一条有分数的记录（0 最干净，100 最差）；账号被限制按 100；没有分数按“无评分时按分数”。
- 金额在拆开时由服务端决定；账本来源 `newbie:{packet_id}` 唯一，重复请求返回同一金额。

## 归因

- 新用户：海报二维码 → `/i/{邀请码}` 落地页 → 输入手机号预绑定 → 下载并用同一手机号注册，自动绑定邀请人，并成为本期成员（kind=new）。
- 已安装 App 的用户：落地页“打开 App 领红包” → `xiaochengyouxi://invite?code=XXXXXX` → `InviteLinkActivity` 记下邀请码 → 登录后调用 `POST /api/newbie/accept`（kind=old；本期内注册的用户记为 new）。
- 微信内打开落地页会提示“在浏览器打开”（微信会拦截 App 唤起和 APK 下载）。

## 分享

不接微信 SDK：活动页用 canvas 画海报（含邀请二维码），通过 `OrangeApp.sharePoster(target, pngBase64, text)` 交给 App。
- `wechat`：直接调起微信“发送给朋友”。没装微信时改用系统分享。
- `moments`：先把海报保存到相册，再打开微信；微信不接受第三方直接发朋友圈图片。
- `save`：只保存到相册。

旧版 App 没有该桥接方法，会退回为分享文字链接。

## 接口

| 接口 | 说明 |
|---|---|
| `GET /api/newbie` | 本人状态：新人红包、待拆邀请红包、好友列表（脱敏）、邀请码/链接 |
| `POST /api/newbie/open {packet_id}` | 拆红包，返回金币与最新状态 |
| `POST /api/newbie/accept {invite_code}` | 已注册用户接受本期邀请 |
| `GET /api/newbie/public` | 落地页用：是否开启、受邀新用户最高金额 |
| `GET/PUT /api/admin/newbie` | 后台配置与统计；`new_round: true` 开启新一期（写管理审计） |
