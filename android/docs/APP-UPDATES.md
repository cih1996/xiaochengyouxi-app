# 原生更新与公告 · Android 0.3.16

隐私确认及服务配置加载之后调用 `GET /api/app/update?version_code=19`，先处理启动更新，再进入已有开屏和账号流程。设置页可查看当前版本并手动检查。自动检查失败记录带接口、版本的错误日志；手动检查显示实际错误并可重试。

更新界面使用现有小橙插画和原生暖色卡片。可选版本可稍后，必要版本只能更新或退出。已识别的最低版本要求保存在应用私有偏好中；新红包、签到、红包雨加入/点击领取、提现在实际请求前统一受门禁限制。已经发出的请求及原广告会话的状态查询、合法确认入账照常完成。广告、领取弹层和动画期间延后更新提示。

APK 从发布信息中的 HTTPS 不可变版本地址下载至 `cache/updates/`；HTTP 跳转返回真实状态码，由发布方提供最终 HTTPS 地址。下载文件大小、SHA-256、包名、精确 versionCode 以及当前签名集合全部匹配后才进入系统安装。校验失败保留实际错误并清除坏缓存；每次下载使用独立临时文件。取消、销毁或过期下载结果均不能启动安装。

`${applicationId}.update-files` 仅授权读取 updates 缓存，使用 `FLAG_GRANT_READ_URI_PERMISSION` 交给系统安装器。Android 8 以上先检查安装来源授权；返回应用后重新校验安装文件并继续。Activity 状态保存保留安装授权恢复所需的公开版本信息。后台完成时关闭下载/校验进度，恢复后显示继续安装或真实错误重试。

`GET /api/app/runtime` 的公告在启动、前台恢复及前台每 45 秒刷新。revision 改变时仅替换固定公告栏文本；空内容隐藏，点击可读全文。进入后台停止定时刷新。奖励、雨和广告策略继续使用各自已有接口。

官方接口依据：[PackageManager](https://developer.android.com/reference/android/content/pm/PackageManager)、[SigningInfo](https://developer.android.com/reference/android/content/pm/SigningInfo)、[FileProvider](https://developer.android.com/reference/androidx/core/content/FileProvider)。本版进行源码交叉审查、Debug/Release 构建与发布签名核验，未执行设备安装。
# 原生 0.3.8 · DeviceTrust 0.6 与行为采集

`versionCode 11` 使用 DeviceTrust 0.6.0 启动登记，并在登录后按服务端策略开启本应用行为采集。采集数据通过 OBA1 AES-GCM 批次与 Keystore P-256 签名上报，登录会话、页面、点击、手势、停留和服务端业务编号按服务端账本关联；敏感输入内容、截图、金额文本和其他应用不进入采集。

发布说明：升级 DeviceTrust 0.6、完善账户安全与行为分析。

# 原生 0.3.9 · 商品点击与正式服务文案

`versionCode 12` 增加商品详情和外链点击上报，服务端失败不影响商品浏览和跳转；捡漏页顶部图片由后台配置，未配置时隐藏。更新正式主体、隐私与服务说明，提现状态以页面和实际审核结果为准。

# 原生 0.3.10 · 可配置营销活动

`versionCode 13` 接入服务端 `/api/campaign` 活动配置、机会、转盘与待结算奖励接口。活动标题、入口、图片、时间窗口、机会和奖励档位由服务端热更新，客户端只展示服务端状态并提交机会编号；转盘奖励需通过结算接口入账。

# 原生 0.3.11 · 登录路径优化

`versionCode 14` 首次启动在隐私同意后直接进入品牌登录页；已有有效会话继续验证并进入大厅，会话失效后清理 token 回到登录。邀请码绑定流程保持不变。

# 原生 0.3.12 · 七日签到与大厅节流

`versionCode 15` 展示七日签到进度、当日签到与补签入口；服务端返回的金币到账继续使用金币动画与音效。大厅推送按服务端节流配置刷新，用户会话与活动状态保持不变。

# 原生 0.3.13 · 验证码登录

`versionCode 16` 默认使用手机号与验证码登录；注册和找回密码继续使用验证码并设置密码。连续登录失败时按服务端要求展示算术安全验证，验证通过后继续登录。

# 原生 0.3.14 · 账号协议与注销

`versionCode 17` 登录和注册页面提供用户协议、隐私政策入口；账号设置支持提交注销申请。

# 原生 0.3.15 · 设置与注销审核

`versionCode 18` 将账号设置改为独立页面。注销申请进入审核状态页并保留本机登录状态，可刷新 `GET /account/deletion-status`；审核通过后再清理登录状态。

# 原生 0.3.16 · 注销确认页

`versionCode 19` 将注销确认改为独立页面，提交申请后进入注销审核状态页。
