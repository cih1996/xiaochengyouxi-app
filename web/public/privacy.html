一、政策导言

本政策由广西奇易电子商务有限公司（以下简称“我们”）制定，适用于“小橙有喜”Android应用（包名：com.lingzidev.xiaochengyouxi）、官方网站及相关账号服务。我们按照合法、正当、必要和诚信原则处理个人信息，并只在本政策说明的目的和范围内使用。

本服务面向成年人。我们不以儿童为主要用户，不主动收集未成年人个人信息。

二、我们收集和使用的信息

1. 注册、登录和账号管理

当您注册、登录或找回密码时，我们收集您的手机号码、昵称、密码校验值和短信验证码，用于创建账号、核验身份、登录和找回密码。密码不会以明文保存。手机号是账号服务的必要信息；不提供手机号将无法注册或登录。

当您通过邀请页注册或绑定关系时，我们收集邀请码、邀请来源和手机号关联结果，用于建立邀请关系、计算邀请机会和展示活动进度。

2. 福利、活动和金币

当您签到、观看激励视频、参加红包雨、转盘或其他任务时，我们收集账号ID、任务ID、活动机会ID、奖励金币数量、操作时间、结算状态和金币收支记录，用于确认任务完成、避免重复发放、处理待结算奖励和展示收益明细。

活动转盘的机会由登录、有效激励视频和有效邀请等服务端规则产生。客户端不能自行提交机会数量或奖励金额。

3. 提现

提交提现申请时，我们收集提现金额、提现方式、您填写的收款账号、申请时间和审核状态，用于审核提现、处理支付和展示提现记录。未提交提现申请时，我们不会收集收款账号。提现是否开通、实际到账时间和支付服务商处理结果以页面及服务商实际状态为准。

4. 商品推广和活动推荐

浏览或点击商品时，我们记录商品ID、曝光、详情打开、外链跳转、点击时间和账号或匿名会话标识，用于商品统计、推广归因和改善展示。当前大厅内容按照活动配置和服务状态展示，不根据您的个人信息进行个性化消息推送。

6. 设备安全核验与行为审计

经您同意并登录账号后，DeviceTrust设备核验组件可能处理设备品牌与型号、系统版本和安全补丁、系统构建信息、网络接入方式、运营商代码、VPN、调试或模拟器线索、应用包名、应用版本、安装来源、签名摘要、随机安装标识、设备标识（ANDROID_ID）以及Widevine设备标识的SHA-256摘要，用于异常领奖、签到和提现核查。Widevine设备标识的原值不离开您的手机，只上传不可逆摘要，用于在重新安装应用后识别同一台设备。

为识别作弊工具和自动化操作，组件还会逐个检测固定名单内的Root、Hook、多开、自动化脚本、虚拟定位、抓包、改内存及远程控制类工具是否安装（不读取完整应用列表），读取已开启无障碍服务的包名与能力、USB调试和开发者选项状态、HTTP代理、本应用进程的调试与注入痕迹、本机回环地址上的监听端口，并统计本应用内触摸事件中疑似模拟点击的数量（不记录触摸内容）。ANDROID_ID仅在同一开发者签名的应用间一致，用于识别同一设备上的风险，不作为登录或身份凭证。

位置与基站信息（可选）：首次签到、领取红包或提现前，我们会先说明用途，再请求系统定位权限。授权后，DeviceTrust 设备核验组件会读取粗略/精确位置以及当前连接和附近的移动基站信息（运营商代码、位置区码、基站编号、信号强度），与 IP 及网络信息交叉校验，仅用于识别虚拟定位、云手机、批量设备等作弊环境，不用于广告推送或个性化推荐。您拒绝授权不影响签到、领红包和提现，相关核验项不参与评分；您可以随时在手机“设置 → 应用 → 小橙有喜 → 权限”中关闭。

为识别批量设备、云手机和群控作弊，组件会读取当前Wi‑Fi或以太网的内网IP地址与网段、默认网关、DNS和DHCP服务器地址、网卡名称（不读取Wi‑Fi名称和周边Wi‑Fi列表）；在核验服务下发检测目标时，还会在约3秒内检测同一网段内指定地址是否可达、是否开启无线调试端口，只检测本机所在网段的地址，不读取其他设备上的内容。

在相关功能开启后，我们还会记录页面进入和离开、前后台切换、控件操作名称、页面停留时长、相对触点位置和手势时长，用于活动分析、奖励核对和安全审计。该记录不包含屏幕录像、屏幕截图、输入文字、密码、短信验证码或其他应用的操作内容。行为报告使用加密和签名方式提交，管理人员查看的是结构化事件和时间线，不是屏幕录像。

三、Cookie和同类技术

官方网站不加载Android广告SDK，也不使用第三方广告Cookie。网站使用浏览器本地存储保存登录状态和必要的页面设置；管理后台使用会话存储保存后台登录状态。您可以清理浏览器站点数据或退出账号删除本地登录状态，清理后可能需要重新登录。

四、信息共享、转让和公开披露

我们不会出售您的个人信息，也不会将账号、手机号、收款账号公开展示。为提供服务，我们可能在必要范围内与以下接收方共享相应信息：

  • 第5节所列广告SDK（穿山甲广告SDK、抖音SDK（安卓版）、快手联盟（Android）、百度移动广告SDK、百度oCPX转化追踪SDK、优量汇 Android SDK）：OAID、设备、网络、广告交互和性能信息，用于广告展示、效果统计和反作弊；观看激励视频时另提供账号编号和奖励编号，用于奖励核对。
  • 腾讯云短信服务（腾讯云计算（北京）有限责任公司）：在您获取验证码时提供手机号和验证码内容，用于发送短信。
  • DeviceTrust设备核验服务：设备安全核验信息、随机设备标识和关联业务事件，用于风险识别。
  • 短信、支付或提现服务商：在您使用验证码或提现功能时，提供手机号、提现金额、收款方式和收款账号等必要信息。
  • 商品推广平台：在您点击商品并跳转购物平台时，按相应平台规则进行必要的推广归因，不共享与归因无关的密码或短信验证码。

我们会要求接收方按照适用法律和协议保护信息。发生合并、分立或服务转让时，若处理目的发生变化，我们会重新告知并依法取得同意。根据法律法规、司法机关或行政机关要求，或为保护用户、平台和公众安全，我们可能依法共享或披露必要信息。

五、信息保护措施

我们采取访问鉴权、密码加密校验、HTTPS传输、服务端权限控制、操作审计、设备密钥签名和活动机会单次消耗等措施保护信息。我们会限制员工和服务商的访问范围，并记录必要的管理操作。发生个人信息安全事件时，我们将依法采取补救措施、降低影响，并在法律要求的范围内及时告知您。

六、信息存储和保留

当前账号、奖励、提现和审计数据存储在中国境内的服务端。我们不会将个人信息传输至境外；如业务确需跨境传输，我们会依法单独告知并取得必要同意。

账号信息在账号存续期间保存；设备核验和行为审计记录原则上自采集之日起保存不超过12个月；奖励、提现和安全审计凭证按照财务、争议处理和法律要求保存。账号注销或保存期限届满后，我们会删除或匿名化处理；法律法规要求继续保存的除外。

七、您如何管理个人信息

  • 您可以在“我的”查看余额、收益明细和提现记录。
  • 您可以在账号设置中修改密码、退出账号。
  • 您可以撤回隐私同意、停止使用广告或活动功能；撤回前已依法处理的信息不受影响。
  • 您可以通过App“我的 → 设置 → 注销账号”进入独立确认页，提交注销申请；申请会进入客服审核状态，审核期间您可以在“注销审核”页面查看进度。审核通过后，我们会停止提供账号服务并删除或匿名化可删除的信息；审核驳回时会展示处理说明，您可以重新提交。
  • 我们会在收到有效申请后15个工作日内反馈审核结果。奖励、提现和安全审计记录会按照财务、争议处理及法律法规要求保留或匿名化。

为保护账号安全，我们可能要求您完成手机号或其他必要的身份核验。我们不会要求您提供与请求无关的密码或短信验证码。

八、未成年人保护

本服务面向成年人。未满18周岁不得注册、参与现金兑换、提交收款账号或参与需要个人信息的活动。若监护人发现未成年人在未经同意的情况下向我们提供信息，请通过App“帮助与反馈”联系我们，我们会核实并依法处理。

个人信息处理主体：广西奇易电子商务有限公司。

账号注销渠道：打开小橙有喜App，进入“我的 → 设置 → 注销账号”，在确认页提交申请后等待客服审核。其他个人信息请求可进入“我的 → 帮助与反馈”。我们将在收到有效请求后15个工作日内反馈处理结果。涉及账号、奖励或提现的请求，可能需要提供必要的账号信息以便核验。

十、政策变更

当收集使用目的、信息类型、共享对象或用户权利发生重大变化时，我们会更新本政策，并通过App启动提示、页面公告或版本更新等方式告知您；需要重新取得同意的，我们会在继续处理前重新征得同意。
